An AI-powered customer support chatbot built while exploring LLM applications and RAG.
The chatbot connects an LLM with structured customer data stored in MySQL, allowing it
to retrieve relevant information and respond to questions about orders, refunds,
subscriptions, and products.

**What it does**
- Retrieves real order information from the database
- Checks order status and order details
- Answers refund and subscription questions
- Uses conversation context
- Handles unavailable information without making up records
